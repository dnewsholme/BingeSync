How to connect Plex to BingeSync
1

Open Plex Web Settings

Log in to Plex Media Server web client as administrator or Plex Pass user, click the Wrench icon (Settings) in the top right.

2

Navigate to Webhooks

In the left sidebar under Manage, select Webhooks.

3

Add Webhook

Click Add Webhook, paste your personal Plex Webhook URL above, and click Save Changes.

4

Start Binging!

Whenever you play or finish watching movies and series, Plex automatically sends scrobbles to BingeSync in real-time.

How to connect Jellyfin to BingeSync
1

Install Jellyfin Webhook Plugin

In the Jellyfin Dashboard, go to Plugins > Catalog, install the official Webhook plugin, and restart your server if prompted.

2

Add Generic Destination

Open Plugins > Webhook settings, click Add Generic Destination, and name it BingeSync.

3

Paste Webhook URL & Select Events

Paste your personal Jellyfin Webhook URL above. Under Notification Type, check PlaybackStart, PlaybackProgress, PlaybackStop, and UserDataSaved.

4

Save & Enjoy!

Click Save. Playback and completed watches from Jellyfin will now automatically scrobble to BingeSync!

How to connect Emby to BingeSync
1

Open Emby Server Settings

In Emby Web, click the Gear icon (Settings) > Server > Webhooks.

2

Add Webhook

Click Add Webhook, paste your personal Emby Webhook URL above.

3

Select Playback & User Events

Enable Playback events (Playback Start, Pause, Unpause, Stopped) and Scrobble / Watched events.

4

Save & Enjoy!

Click Save. Media watched on your Emby server will now scrobble in real-time!
